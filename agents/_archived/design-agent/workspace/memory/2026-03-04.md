### Design Decisions

1. **P0-1: distribute() 负载不均衡**
   - Root cause: Initial distribution unrelated to ParMETIS partition results
   - Solution: Distribution-aware pre-alignment with partition hints
   - Trade-off: Slightly increased complexity, major communication reduction

2. **P0-2: Interface 通信效率低**
   - Root cause: String serialization + full Allgather
   - Solution: Binary serialization + sparse point-to-point communication
   - Trade-off: Need to handle endianness (low risk for homogeneous clusters)

3. **P1: 字符串匹配效率低**
   - Root cause: Multiple string conversions and allocations
   - Solution: Use P0-2 binary format directly, eliminates string overhead
   - Trade-off: None significant, purely performance improvement
